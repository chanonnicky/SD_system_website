ติดตั้งแอปลงเครื่อง

Android
Chrome Browser
  1. 1 เปิด Chrome แล้วไปที่ลิงก์ Admin Panel
  2. 2 กดไอคอน ⋮ (3 จุด) มุมขวาบน แล้วเลือก "ติดตั้งแอป" หรือ "เพิ่มในหน้าจอหลัก"
  3. 3 กด "ติดตั้ง" เพื่อยืนยัน — ไอคอนแอปจะปรากฏที่หน้าจอหลัก
  4. 4 เปิดแอปจากไอคอนที่หน้าจอหลัก แล้วทำขั้นตอนที่ 2
iPhone / iPad
Safari Browser · iOS 16.4+
  1. 1 เปิด Safari (ต้องใช้ Safari เท่านั้น — Chrome บน iOS ไม่รองรับ)
  2. 2 ไปที่ลิงก์ Admin Panel แล้วกดไอคอน แชร์ ที่แถบด้านล่าง
  3. 3 เลื่อนหาแล้วกด "เพิ่มไปยังหน้าจอเริ่มต้น" (Add to Home Screen)
  4. 4 กด "เพิ่ม" มุมขวาบน — ไอคอนแอปจะปรากฏที่หน้าจอหลัก
สำคัญมาก: ต้องเปิดแอปจากไอคอนที่หน้าจอหลักเท่านั้น ถ้าเปิดจาก Safari ปกติจะไม่ได้รับการแจ้งเตือน
2

เปิดรับการแจ้งเตือน

  1. 1
    Login เข้าหน้า Admin Panel
    เปิดแอปจากไอคอนที่หน้าจอหลัก (ไม่ใช่จาก browser โดยตรง)
  2. 2
    กดปุ่ม กระดิ่ง มุมขวาบน
    ถ้ากระดิ่งเป็นสีเขียวแล้ว แสดงว่าเปิดไว้แล้ว
  3. 3
    กด "Allow" หรือ "อนุญาต" เมื่อ browser ถาม
    ถ้าไม่มีป๊อปอัปขึ้น อาจถูกบล็อกไว้แล้ว → ดูหัวข้อแก้ปัญหาด้านล่าง
  4. ✓
    กระดิ่งเปลี่ยนเป็นสีเขียว = สำเร็จ
    ระบบจะแจ้งเตือนทุกครั้งที่มีงานซ่อมหรือจองห้องใหม่

ตรวจสอบและทดสอบ

ตรวจสอบระบบ
ดูว่าอุปกรณ์นี้พร้อมรับแจ้งเตือนหรือยัง
ส่งการแจ้งเตือนทดสอบ
ส่ง notification ไปยังทุกอุปกรณ์ที่ลงทะเบียนไว้

แก้ปัญหาที่พบบ่อย

กดกระดิ่งแล้วไม่มีป๊อปอัปขึ้น

การแจ้งเตือนอาจถูกบล็อกไว้ก่อนหน้า
Chrome: กด 🔒 ที่ address bar → Site settings → Notifications → Allow
Safari iOS: ตั้งค่า → Apps → Safari → เว็บไซต์ → เว็บไซต์นี้ → Allow

ลงทะเบียนแล้วแต่ไม่ได้รับแจ้งเตือน (iOS)

ต้องเปิดแอปผ่านไอคอนที่หน้าจอหลักเท่านั้น ไม่ใช่จาก Safari โดยตรง
ตรวจสอบ iOS version ≥ 16.4

ส่งทดสอบแล้วขึ้นว่า 0 เครื่อง
